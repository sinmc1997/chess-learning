# 西洋棋學習

網址：https://sinmc1997.github.io/chess-learning/

按 `LEARNING_SITE_BLUEPRINT.md`（形態訓練營藍圖）做嘅學習網站：題目隨機生成、答錯係資料、間隔重複、智能揀題。
純前端，唔使伺服器，雙擊 `index.html` 或者 GitHub Pages 都得。

## 功能
- **🎮 關卡**：15 關（車象 → 馬 → 后王 → 兵 → 走法混戰 → 子力 → 將軍 → 叉 → 牽制串擊 → 一步殺 → 規則開局 → 后殺馬殺 → 對立同方格 → 王兵殘局 → 畢業考），答啱 80% 過關，攞星解鎖下一關。
- **圖文解釋**：每課都有示意棋盤（綠點＝可以去、紅框＝目標、藍框＝主角）同說明。
- **智能練習**：每輪 10 題，按到期複習 > 未學 > 弱項 揀題，同一項目唔會連續出。
- **學習課程**：22 課（走法、子力價值、將軍、叉、牽制、串擊、底線將死、后殺、馬殺、升變、吃過路兵、王車易位、開局原則、王嘅對立、方格法則、王兵殘局），每課有示範（揭示）、原理、常見失敗、主動回憶自評（唔記得／勉強／記得）。
- **即時重溫**：答錯嘅課會喺同一輪 2 題之後換一題再考（每輪最多加 3 題）。
- **錯題本**：答錯自動入庫，可以重做同一幅圖（seed 確定性），寫低自己點解錯。
- **統計**：每課正確率、掌握度、估中率（信心校準）、最常混淆。
- **學習路徑**：學完 → 最近 20 題 ≥80% → 每項掌握 ≥50% → ≥80% 畢業。
- **備份**：下載／還原 JSON。

## 檔案
- `index.html`：頁面殼＋樣式
- `engine.js`：通用引擎（SM-2、Elo、智能揀題、錯題本、統計、備份）— 同粵拼網站共用
- `content.js`：西洋棋內容（22 課、生成器、概念題庫、迷你規則引擎、王兵殘局表）
- `tests/validate.cjs`：`node tests/validate.cjs` 每個生成器跑 1500 個 seed，檢查每題剛好 1 個正解、冇重複選項
- `tests/chess_rules.cjs`：用另一套規則重新讀棋盤，核對「邊粒將軍」、底線殺、后殺、馬殺（錯選項唔可以都係將死）；方格法則用逐步搜尋核對；王兵殘局表用經典局面核對
- `tests/smoke.cjs`：假 DOM 走一遍主流程

## 注意
- 題目係模擬練習，走法以空棋盤為準（唔計阻擋），學習重點係記住規則同常見戰術。
- 題型：一步可去邊格、馬落點數、叉位、邊粒將軍（計阻擋）、底線一步殺、后殺、馬殺、對立、方格法則、王兵殘局（唯一贏棋一步）、子力計數、概念題。
- 一步殺、殘局題計足規則（阻擋、牽制、擋、吃）；唔計易位同吃過路兵。
